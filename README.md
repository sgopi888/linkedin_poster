# LinkedIn Poster

AI-powered LinkedIn content generation pipeline using:
- OpenRouter
- DeepSeek
- ComfyUI / Comfy Cloud
- LinkedIn API
- Discord orchestration

Features:
- AI research agent
- Founder-style LinkedIn writing
- AI image generation
- LinkedIn auto-posting
- Dynamic orchestration pipeline
- Discord integration (WIP)

Architecture:
Discord/User Input
→ Content Orchestrator
→ Image Agent
→ Review Layer
→ LinkedIn Publisher
